# InsuranceAI Enterprise Frontend Skill

This skill is designed for building high-quality frontend interfaces for InsuranceAI.

InsuranceAI is:
- an AI-assisted insurance underwriting platform
- broker-facing infrastructure software
- operational workflow tooling
- enterprise SaaS
- NOT a consumer app
- NOT a flashy startup landing page
- NOT a crypto dashboard
- NOT an experimental art project

The frontend should feel:
- premium
- trustworthy
- technical
- operational
- modern
- restrained
- realistic
- production-grade

The goal is:
> software that real insurance brokers would actually use daily.

---

# Core Frontend Philosophy

Build interfaces that feel:
- intentional
- engineered
- refined
- structured
- believable

Avoid:
- generic AI-generated layouts
- fake SaaS dashboards
- random analytics widgets
- visual clutter
- excessive gradients
- gimmicky animations
- overengineered frontend abstractions

The frontend should emphasize:
- hierarchy
- clarity
- usability
- information density
- polished spacing
- subtle visual sophistication

---

# CRITICAL BACKEND REALITY RULE

Never invent fake product functionality.

ONLY build UI for systems that actually exist in the backend.

If the backend does not support something:
DO NOT create frontend UI for it.

Never invent:
- fake analytics
- fake infrastructure systems
- fake notifications
- fake AI metrics
- fake billing systems
- fake subscription systems
- fake producer management
- fake enterprise reporting
- fake operational monitoring
- fake carrier integrations
- fake automation pipelines
- fake workflows

Frontend must remain tightly aligned to:
- real database models
- real API endpoints
- real workflows
- real entities
- real backend capabilities

# Backend Protection Rules

Do NOT autonomously:
- refactor backend architecture
- redesign backend systems
- rename core backend models
- split backend into unnecessary abstractions
- introduce enterprise architecture patterns
- rewrite business logic
- create new backend layers
- modify API contracts unless explicitly requested

The backend architecture is intentionally engineered manually.

AI assistance is primarily for:
- frontend polish
- UI generation
- layout refinement
- styling
- reusable components
- dashboard composition

NOT backend takeover.
